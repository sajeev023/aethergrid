3. Technical Architecture (How It's Built)

🎨 Front End

  • Next.js 15 App Router: Server Components combined with interactive Client components for instant navigation.
  • React 19 & Tailwind CSS 4: High-performance modern utility styling with bespoke dark-mode aesthetic.
  • Framer Motion & Lucide: Micro-animations, progress meters, and dynamic telemetry cards.
  • Responsive UI: Tailored views for mobile simulators, giver controls, and file explorers.

⚙️ Back End

  • Node.js 24 + Web Crypto: High-speed cryptographic primitives (HKDF, AES-256-GCM, SHA-256).
  • Storage Orchestrator: Multi-replica 2MB chunking engine with automatic capacity reservation and disk safety limits.
  • Auth & Defense: HttpOnly JWT sessions via jose, Bcrypt password hashing, and IP rate limiting.
  • 60s Scoped Signed Tokens: Single-use download authorizations to prevent URL leakage.

🗄️ Database

  • Native SQLite (node:sqlite): High-throughput zero-latency embedded database in WAL mode.
  • Relational Schema: 10 tables managing users, sessions, storage nodes, chunks, files, allocations, and ledger payouts.
  • Dual-Platform Adaptability: Runs against local NTFS physical disks (D:\AetherGridStorage) and Vercel serverless mounts (/tmp).
